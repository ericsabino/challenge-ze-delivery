# challenge-ze-delivery
Desafio backend proposto pelo Zé Delivery

## 📚 Documentação Completa

Este repositório possui **documentação abrangente** criada especificamente para facilitar o entendimento e uso do sistema:

### 🎯 Documentos Principais
- **[RESUMO_DOCUMENTACAO.md](./RESUMO_DOCUMENTACAO.md)** - Visão geral completa e ponto de entrada para toda documentação
- **[DOCUMENTACAO_COMPLETA.md](./DOCUMENTACAO_COMPLETA.md)** - Documentação detalhada do sistema, arquitetura e funcionalidades  
- **[ANALISE_TECNICA.md](./ANALISE_TECNICA.md)** - Análise profunda do código, padrões e estrutura técnica
- **[API_DOCUMENTATION.md](./API_DOCUMENTATION.md)** - Documentação completa da API REST com exemplos
- **[GUIA_INSTALACAO.md](./GUIA_INSTALACAO.md)** - Guia passo-a-passo para instalação e deploy

### 🚀 Quick Start
```bash
git clone https://github.com/ericsabino/challenge-ze-delivery.git
cd challenge-ze-delivery
mvn clean install
docker-compose up -d
```

**➡️ Para informações detalhadas, consulte [RESUMO_DOCUMENTACAO.md](./RESUMO_DOCUMENTACAO.md)**
